# MIO Distribution

This repository hosts MIO installers, the automatic-update manifest, and the static distribution website published through GitHub Pages. The application source is maintained in a separate private repository.

- Website: [MIO distribution page](https://donggeonbae.github.io/multi-insurance-optimizer-updates/).
- Installers: [latest GitHub Release](https://github.com/donggeonbae/multi-insurance-optimizer-updates/releases/latest).
- Update manifest: [update_manifest.json](https://github.com/donggeonbae/multi-insurance-optimizer-updates/releases/latest/download/update_manifest.json).

Customer PDFs, analysis results, and consultation notes are not stored on the server.

## Release privacy

Keep customer-identifying information out of release titles, notes, manifests, and asset names. Do not publish customer names, identifiers, order numbers, original document filenames, or local file paths.
