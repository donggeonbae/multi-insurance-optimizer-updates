진료내역 정리부터
고지문과 설계표까지.

MIO는 기본진료내역·세부내역서·처방 PDF를 바탕으로 상담용 병력 정리, 고지 후보 검토, 제3보험/생명보험/손해보험 설계표 관리를 돕습니다.

⬇ Windows 설치 프로그램  macOS 설치 프로그램

최신 버전 확인 중 · 설치 후 앱 실행 시 자동 업데이트를 확인합니다. Windows SmartScreen이 표시되면 “추가 정보 → 실행”을 선택해야 할 수 있습니다.

사용 예시

  1. 고객의 기본진료내역 PDF와 세부내역서 PDF를 넣고, 처방 PDF가 있으면 함께 넣습니다.
  2. 진료 기록 열람에서 입원·수술·약처방·타임라인을 확인하고 수술 검토대상은 필요한 항목만 고지문에 포함합니다.
  3. 건강체/간편체 고지용 문구를 복사해 상담 기록에 저장하고, 원본 근거는 펼쳐서 다시 확인합니다.
  4. 제3보험·생명보험·손해보험 설계표에서 보험사 → 상품명 → 담보/플랜 순서로 선택하고 월보험료 합계를 비교합니다.

주요 기능

고지 후보 자동 분류, 약처방 보강, 수술 검토 체크, 상담 메모 저장, 보험상품 공시 DB 선택, Excel/CSV 내보내기를 제공합니다.

개인정보 및 책임 안내

MIO는 고객 PDF, 분석 결과, 상담 메모, 설계표 등 개인정보성 데이터를 서버에 저장하지 않습니다. 프로그램 사용 중 생성되는 업무 데이터는 사용자의 PC 로컬 저장소에 저장됩니다.

사용자의 PC 보안, 파일 공유, 백업/동기화 설정, 외부 전송 과정에서 발생하는 개인정보 유출 및 업무상 판단 결과는 사용자 책임입니다. MIO는 보험 가입·심사·인수 결과를 보장하지 않으며, 최종 고지/설계 판단은 원본 자료와 보험사 기준으로 확인해야 합니다.
